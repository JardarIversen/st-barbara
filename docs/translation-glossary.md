# Engelsk kirkelig språk

Denne ordlisten styrer agentens redaksjonelle oversettelser, ikke en automatisk søk/erstatt-operasjon.

| Norsk | Engelsk |
| --- | --- |
| messe (alene) | Holy Mass |
| messe i en tydelig kirkelig setning | Mass |
| messetider | Mass times |
| høymesse | Sunday Mass (ikke anta sung/solemn uten kilde) |
| kirkevigsel | consecration of the church |
| vigsling av alteret | consecration of the altar |
| vielse av et par | wedding / marriage |
| rosenkrans | Rosary |
| skriftemål | confession |
| katekese | catechesis |
| første kommunion | First Holy Communion |
| konfirmasjon / ferming | Confirmation |
| sogneadministrator | parish administrator |
| menighetsråd | parish council |
| søndagsblad | Sunday bulletin |
| lesninger | readings |
| evangelium | Gospel |
| kunngjøringer | notices |
| kirkekaffe | coffee after Mass |
| p. Trym | Fr Trym |

Behold personnavn, stedsnavn, adresser, datoer, tidspunkter, betalingsinformasjon og lenkemål. Ikke legg til presiseringer som kilden ikke støtter. Kontrollér kirkelige titler, avlysninger og frister særskilt. «Mass» skal aldri bli «fair», og kirkevigsel er ikke en bryllupsfeiring.

Oversettelser av brev må merkes som oversettelser. Bibel- og messetekster skal ikke AI-oversettes som erstatning for en godkjent liturgisk oversettelse. Engelsk nettsidespråk betyr ikke at messen feires på engelsk.
