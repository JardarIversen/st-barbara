# Videre arbeid

Forslag og oppgaver som prioriteres sammen med Jardar.

## Innhold

- «Ny her?»-side med introduksjon til messen, fellesskapet og voksenopplæring.
- Lett tilgjengelig informasjon om gravferd og sykebesøk.
- Flere menighetsbilder: kirkerom, rosevindu, levende lys og eksteriør.
- Galleri for kirkevigselen og menighetsaktiviteter.
- Vurdere hvilke innlegg og bilder som skal være tilgjengelige i arkivet.

## Funksjonalitet og kvalitet

- Påmeldingsløsning for katekese.
- Egen 404-side med nyttige lenker.
- Delingsbilde med kirkebilde og menighetsnavn.
- Tilgjengelighetsgjennomgang: kontrast, tastatur og skjermleser.
- Personvernerklæring som beskriver faktiske tjenester og informasjonskapsler.
- Kontrollere at publisering og sletting i Sanity oppdaterer nettsiden automatisk.

## Drift

- Avklare langsiktig eierskap og tilgang til GitHub, Vercel og Sanity.
- Redaksjonell gjennomlesing av sentrale språk.
- Brukerveiledning for innlegg, messeplaner og søndagsblader.
